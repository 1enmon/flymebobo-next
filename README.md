# flymebobo 2.4

LSPosed 模块，把通知变成贴在屏幕左边的悬浮气泡（胶囊）——音乐、下载、验证码 / 取件码、来电、实况都有。

包名 `com.chenan.flymebobo`，versionName `2.4`。在 Flyme（MEIZU 20 Pro）上验证过；核心是通用 Android，但小窗打开用 Flyme WindowManagerExt，有些 hook 针对 SystemUI 内部。

## 功能

- 每条通知都弹成一个 180x44dp 的胶囊，按应用图标主色着色，贴在屏幕左边缘。通知永不自动展开。
- 点胶囊展开成卡片；点卡片打开对应的 App（默认小窗打开，开关关了全屏打开）。
- 每条通知可单独钉住；钉住的胶囊和卡片排在最上面。
- 音乐胶囊：实时歌词、专辑图、进度条和播放控制；播放时有音符粒子、音量条、歌名呼吸和滑入动效。
- 下载胶囊：实时进度、速度和剩余时间；应用商店的安装进度也包含。
- 验证码 / 取件码自动识别、放大、自动钉住，验证码自动复制。
- 来电胶囊：通过系统来电通知自带的按钮接听 / 挂断 / 扬声器。
- 推送代发的通知显示真实应用（比如 BOSS 经魅族云推送发的，气泡显示 BOSS 直聘）。
- 设置 App（MainActivity），功能开关实时生效，拨动后不用重启 SystemUI。
- 设置 App 底部的链接：源码仓库、酷安主页、"请我喝咖啡"微信收款码。

当前版本：v2.4（versionCode 501）。

## v2.4 更新

- 外观细调全家：外观卡里胶囊、卡片、扇子全部可调（胶囊圆角/高度/宽度，卡片宽度/圆角/最大行数/比例，扇子图标重叠度/排列方向/位置），拖滑块自动展开实时预览，底部一键恢复默认。
- 来电：来电卡里来电胶囊圆角/高度/宽度、来电高度都能调；模拟来电开关，弹一颗假来电胶囊调位置用；来电计时器缩后更贴边（左 96dp）。
- 音乐胶囊：音乐卡里音乐胶囊圆角/高度/宽度、音乐卡片宽度/圆角/比例都能调；模拟音乐开关，弹一颗假音乐胶囊调着玩；歌词固定 1 行。
- 反方向的钟：放音乐时屏幕边缘一圈 LED 跑马灯（00 年代老按键机风），音乐停灯灭；点满 100 次才开启，第 100 下先放一遍《反方向的钟》。
- 充电动画：插上充电器，22 片粉色花瓣从顶部飘落到底部淡出，约 3.6 秒，只播一次，全屏不挡点击。
- 自动销毁：「自动消散」卡里多一个子开关：开着，点空白处胶囊消散时系统通知也一起撤销；关着，只消散胶囊，通知还留在通知栏里。
- 本地持久化：设置改完自动备份到 `/sdcard/flymebobo/flymebobo_settings.txt`。覆盖安装、重启、打开一次 App，开关和外观自动回来，不用重新设置。
- 验证码 / 取件码：显示成「xx码:xxxxx」（比如「验证码:123456」「取件码:1234」）。验证码自动复制，取件码不复制，两者自动钉住。
- 胶囊自动取色 + 扇子自动变淡：胶囊自动取色（默认开），胶囊底色取 App 图标的主色；扇子自动变淡（默认开），扇子出现后 5 秒无点击，整排图标变半透明，点一下恢复。
- 推送拦截改走 `IStatusBarService.onNotificationClear`（状态栏“用户划掉通知”接口）；展开卡片左滑改回 1:1 跟手，划过 -140dp 收进扇子。

## v2.3 更新

- 锁屏：气泡能上锁屏，锁屏上的原通知卡片能屏蔽，息屏显示上不显示气泡。
- 来电胶囊重新设计：变大到 240x60，名字和号码都居中；新开关“来电放右边”，开后胶囊单独放右手边屏幕中间偏下；号码能识别（纯数字是号码、其他是名字），11 位裸号按 3-4-4 补空格；接听后缩成只剩计时器一行；胶囊改成从边缘滑入。
- 推送：推送服务包名从 14 个扩到 60+，覆盖全厂商；推送通知撤卡片改走监听服务。
- 微信 / QQ：同一个人的多条消息合并成一个胶囊，原地更新，不再一个一个弹。

## v2.2 更新

- 大卡片模式：普通通知放大成卡片依次排列，点它开 App；轻左滑钉住、重左滑只缩被滑的那一张进扇子；右滑消散带拖尾，点空白自动消散。
- 左滑缩进改成压扁进左边缘，不再往上飞；大卡片左滑不再顶出屏幕卡住。
- 拖尾：点空白自动消散每张卡也带拖尾；拖尾和卡片之间零重叠、没缝。
- 大卡片模式里钉住后仍是一张大卡片，不缩成小胶囊。
- 扇子图标：缩进扇子后小图标左半被窗口裁掉修好了。
- 平板适配：胶囊 260dp、卡片 380dp，进度条改细，手势按胶囊宽等比，窗口防截断，两行字纵向显示修复；APP 右上角加了“重启系统界面”按钮。
- APP 内标题改成 2.2。

## v2.1 更新（自 v310）

- 下载：进度刷新从 1 秒改成 0.5 秒；完成判断放宽，小文件和酷安下完胶囊能正常消散。
- 推送代发显示真实应用：BOSS 这类经魅族云推送代发的通知，气泡显示真实应用名和图标。
- 音乐胶囊动效：音符粒子飘、右边音量条跳、歌名呼吸和滑入。

## 构建

需要 JDK 17+、Android SDK（android-34）、apktool、D8（r8）和 Xposed API jar。见 `build/build20.sh`。
